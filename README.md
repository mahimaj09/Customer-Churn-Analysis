# 📊 Customer Churn Analysis Dashboard

## 📌 Overview

The **Customer Churn Analysis Dashboard** is an interactive Power BI project designed to analyze customer behavior and identify patterns contributing to customer churn. This dashboard helps businesses understand customer retention trends and make data-driven decisions to reduce churn rates.

The project analyzes customer demographics, contract types, payment methods, tenure, and internet services to uncover valuable business insights.

---

# 🎯 Objectives

* 📉 Analyze customer churn behavior
* 👥 Identify factors affecting customer retention
* 💳 Compare churn across payment methods and contract types
* 📊 Visualize trends using interactive dashboards
* 📌 Support business decision-making with analytics

---

---

# 🔍 Key Insights

* 📌 Customers with **month-to-month contracts** show the highest churn.
* 💳 Customers using **electronic check payments** contribute significantly to churn.
* ⏳ Customers with **lower tenure** are more likely to leave.
* 🌐 Fiber optic users represent a large portion of customers.
* 👥 Male and female churn distribution is relatively balanced.
